# Day 02 – Sales Orders Data Analysis

## Project Overview
As part of my 30-Day Advanced Excel + AI learning journey, I worked with a sales orders dataset to understand sales performance and business information using Microsoft Excel.

## Dataset Information
The dataset contains 15 sales records and 10 columns:

- Order_ID
- Employee
- Product
- Order_Date
- Sales
- Discount
- Quantity
- Region
- Payment_Mode
- Status

## Analysis Objectives
- Identify employees appearing most frequently.
- Find products with the highest individual sales.
- Compare regional orders.
- Identify pending and completed orders.
- Analyze discounts.
- Understand sales patterns across products and employees.

## Excel Skills Practised
- Sorting
- Filtering
- Basic data analysis
- Comparing values
- Identifying patterns and trends
- Answering business questions using raw data

## Tools Used
- Microsoft Excel
- AI assistance

## Learning Outcome
Practised exploring raw sales data, identifying important business information and answering business-related questions through data analysis.
